Herramientas y Stack Tecnologico

Para que este proyecto funcione correctamente, se debe utilizar el siguiente stack y dependencias.

Entorno Principal

Node.js: Entorno de ejecucion para el backend.

NPM: Gestor de paquetes de Node.

Dependencias de Produccion

express: Framework web para crear el servidor y manejar las rutas HTTP.

dotenv: Modulo para cargar variables de entorno desde un archivo .env a process.env.

Dependencias de Desarrollo

nodemon: Herramienta que reinicia automaticamente la aplicacion de Node cuando detecta cambios en el directorio, util para agilizar el desarrollo.

Control de Versiones

git: Para gestionar los cambios del codigo fuente. El proyecto debe contener un archivo .gitignore adecuado para Node.js.
